# switch-framework-docs

Official documentation site for **Switch Framework** — the no-build ESM runtime for web and Electron apps.

It covers getting started, layouts, routing, state, theming, the server, desktop (Electron) apps, and publishing Switch npm packages.

## Run locally

```bash
git clone https://github.com/Switcherfaiz/switch-framework-docs
cd switch-framework-docs
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The docs start at `/docs/introduction`.

If the port is different, check `package.json` (`switchFramework.port`) or set `PORT`.

## What you will find

- **Start here:** introduction, quickstart, folder structure, CLI
- **App:** layouts, router, state, hooks, theming, animations
- **UI:** components, Switch icons
- **Install:** web and desktop
- **Server:** Express backend, desktop auth, splash, multiple child servers
- **Packages:** importing and publishing Switch npm components
